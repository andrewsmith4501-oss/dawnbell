# Dawnbell

Three chapters so far: The Warden's Trial, The Hollow Deep and The Gloaming Fen. A top-down action adventure made for phones held sideways, and playable on PC with a keyboard or controller.

**PC keys:** WASD or arrows move, J sword (hold to charge a spin), K shield, Space roll, L target, F claw, G lamp, E potion, M map, Esc pause. Controllers work too (A sword, B roll, X claw, Y lamp, LB target, RB shield, RT potion).

Play it in the browser, or install it:
- **iPhone:** open the link in Safari, tap Share, then Add to Home Screen.
- **Android:** open the link in Chrome, tap the menu, then Install app (or Add to Home screen).

It's a single HTML file with no build step. `sw.js` caches the game for offline play; bump `VERSION` in it whenever you change the game.
